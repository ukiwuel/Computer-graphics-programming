# Обработка изображений: резкость и пороговая обработка

Лабораторная работа 1, вариант 8. Программа на Python (Tkinter, numba) с тремя режимами:

- повышение резкости высокочастотными фильтрами;
- глобальная пороговая обработка;
- адаптивная пороговая обработка.

## Запуск

```
pip install numpy numba pillow matplotlib
python app.py
```

Первый запуск дольше остальных: numba компилирует функции. Для сборки exe: `pyinstaller --onefile --noconsole app.py`.

## Использование

1. Открыть изображение кнопкой «Открыть...».
2. Выбрать обработку краёв: Clamp (дублирование границы) или Reflect (зеркальное отражение).
3. Выбрать вкладку, задать параметры, нажать «Применить».

Слева показывается исходное изображение, справа результат, внизу гистограммы яркости до и после. Для порогов найденное значение отмечено на гистограмме красной линией.

| Вкладка | Методы | Параметры |
|---|---|---|
| Резкость | лапласиан, нерезкая маска | сила `amount`, σ Гаусса |
| Глобальный порог | Оцу, Капур | нет |
| Адаптивный порог | Саувола | размер окна, коэффициент `k` |

## Устройство программы

Код в `app.py` разделён на три слоя:

1. **Доступ к пикселям.** Функция `ix(i, n, mode)` приводит индекс за границей изображения к допустимому по выбранной стратегии (Clamp или Reflect).
2. **Обработка.** Алгоритмы работают с массивами numpy вложенными циклами (numba, `prange` для параллельности) и не зависят от интерфейса.
3. **Интерфейс.** Класс `App`: вкладки, ползунки, показ изображений и гистограмм. Обработка идёт в фоновом потоке, окно не зависает.

## Алгоритмы

**Яркость.** Для порогов изображение переводится в градации серого: `Y = 0.299R + 0.587G + 0.114B`.

**Лапласиан.** `g = f + amount · (L ∗ f)`, ядро L = `[[0,-1,0],[-1,4,-1],[0,-1,0]]`. Свёртка прямая, вложенными циклами.

**Нерезкая маска.** `g = f + amount · (f − G ∗ f)`. Размытие Гауссом считается как разделяемая свёртка: проход по строкам, затем по столбцам (радиус ядра `ceil(3σ)`). Результат обрезается до 0..255. Резкость применяется к каждому каналу RGB отдельно.

**Метод Оцу.** Порог выбирается перебором 0..255 по максимуму межклассовой дисперсии `w0 · w1 · (μ0 − μ1)²`.

**Метод Капура.** Порог выбирается по максимуму суммы энтропий фона и объекта.

**Адаптивный порог.** Для каждого пикселя считаются среднее `m` и СКО `s` в окне вокруг него. Суммы по окну берутся из интегральных изображений (суммы яркостей и их квадратов), поэтому время не зависит от размера окна. Порог по методу Саувола: `T = m · (1 + k · (s / 128 − 1))`.

Пиксель становится белым, если его яркость больше порога, иначе чёрным. Вблизи границы окно обрезается по размерам изображения.

## Особенности работы методов

Выводы получены на синтетических тестовых изображениях (текст на ровном фоне, с градиентом освещения, с пятном тени, с шумом; размытые сцены). На реальных фото числа будут другими.

- Оцу хорошо работает при двух чётких пиках гистограммы (чёткий текст, IoU 0,99). При неравномерном освещении и тени глобальные методы почти не работают (IoU 0,08–0,21), а Саувола даёт 0,97–0,99. Капур на тексте с малой долей объекта оказался хуже Оцу.
- Адаптивный порог чувствителен к шуму: на зашумлённом тексте при `k` = 0,5 лучше брать окно около 15 и сглаживать изображение заранее.
- Нерезкая маска предпочтительнее лапласиана: лучше приближает чёткий оригинал (до +1,9 дБ PSNR) и меньше усиливает шум. Слишком большие σ и `amount` дают ореолы вокруг контуров.
- Для лапласиана 3×3 Clamp и Reflect дают одинаковый результат, у нерезкой маски различия только в полосе нескольких пикселей у края.
- Скорость на изображении 2000×2000: разделяемый Гаусс быстрее прямой двумерной свёртки в 6 раз при σ = 2 и в 15 раз при σ = 5; адаптивный порог 18–26 мс при любом окне.

## Ограничения

- Графический интерфейс не проверялся в автоматическом режиме: проверены сами алгоритмы.
- Современные Python и numba не запустятся на Windows XP.
- Адаптивный порог реализован по методу Саувола; если в лекции другой алгоритм, формулу нужно заменить в `adaptive_apply`.
