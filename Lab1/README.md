# Лабораторная работа №1 — Цветовые модели (Вариант 8: RGB ↔ XYZ ↔ HSV)

Десктоп-приложение на PyQt5, позволяющее задавать цвет тремя способами
(слайдер, точное числовое поле, палитра) и видеть его представление
одновременно в трёх цветовых моделях — **RGB**, **XYZ**, **HSV** — с
автоматическим пересчётом всех представлений при изменении любого из них.

Все преобразования реализованы вручную (без внешних библиотек конвертации
цвета — используются только матричная алгебра и элементарные функции).

## Возможности

- Задание цвета: ползунком, полем точного ввода, стандартным диалогом
  выбора цвета (палитрой) — для каждой из трёх моделей отдельно.
- Автоматический пересчёт всех трёх моделей при изменении любой из них.
- Выбор стандарта освещения (белой точки): **D65** (дневной свет, sRGB),
  **D50** (полиграфия), **E** (равноэнергетический источник). Матрица
  перехода RGB↔XYZ пересчитывается на лету методом адаптации Брэдфорда —
  жёстко заданы только физические константы D65 (сенсоры CIE 1931).
- Две стратегии обработки выхода значения за пределы модели при обратном
  переводе (например, XYZ → RGB даёт компоненту вне [0, 1]):
  - **clip** — обрезание значения до границы диапазона;
  - **scale** — пропорциональное сжатие всего диапазона, чтобы вписать
    цвет в допустимые границы.
  При срабатывании коррекции под образцом цвета показывается
  ненавязчивое предупреждение.
- Динамический градиент под каждым слайдером: показывает, каким станет
  цвет, если подвинуть именно этот слайдер, с учётом текущих значений
  остальных компонент той же модели.
- Кнопка **«ℹ Информация»** в приложении — краткое руководство
  пользователя, не выходя из программы.

## Архитектура (MVVM)

Проект разделён на независимые слои:

| Слой | Файл | Содержимое |
|---|---|---|
| **Model** | `color_models.py` | Чистая математика: матрицы RGB↔XYZ, адаптация Брэдфорда, RGB↔HSV, стратегии clip/scale, класс `ColorModel`. Ничего не знает о Qt/UI. |
| **ViewModel/Controller** | `color_view_model.py` | `ColorViewModel` — принимает команды от View, дергает `ColorModel`, оповещает View Qt-сигналом `colorChanged`. |
| **View** | `main_window.py`, `color_slider.py` | Только виджеты, расположение, обработчики UI-событий. Обращается к модели исключительно через `ColorViewModel`. |

Такое разделение позволяет тестировать математику независимо от
интерфейса (см. `test_color_models.py`) и не даёт логике конвертации
"протекать" в код виджетов.

## Математика

### RGB → XYZ и обратно

Используется линейная матрица 3×3, построенная из координат
хроматичности праймари sRGB и опорной белой точки D65 (физическая
константа CIE). Для стандартов D50 и E эта матрица не хранится как
отдельная константа, а получается адаптацией матрицы D65 методом
Брэдфорда (переход в пространство LMS конусов, масштабирование под
новую белую точку, возврат обратно). Обратная матрица находится
методом Гаусса.

Перед переводом RGB предполагается **линейным** (гамма-коррекция не
входит в эту лабораторную работу — учитывается связка "линейный
RGB ↔ XYZ").

### RGB → HSV и обратно

Стандартные формулы через max/min компонент (см. `rgb_to_hsv`,
`hsv_to_rgb` в `color_models.py`).

### Стратегии коррекции гамута

`clamp_rgb` — покомпонентное обрезание в [0, 1].
`scale_rgb` — линейное масштабирование `(v - min) / (max - min)` по
всем трём компонентам одновременно, сохраняющее пропорции между R, G, B.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

## Сборка .exe (Windows)

```bash
pip install pyinstaller
pyinstaller --onefile --windowed main.py
```
Исполняемый файл появится в папке `dist/`.

## Тесты

```bash
python -m unittest test_color_models -v
```
Тесты проверяют: round-trip RGB↔XYZ↔HSV, соответствие белой точки
эталонным координатам XYZ, различие матриц перехода между стандартами
освещения, корректность стратегий clip/scale и флага выхода за гамут.
